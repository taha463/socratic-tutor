# Plot Skill

## When to Use
Use when teaching mathematical, algorithmic, or machine learning topics:
- Big-O complexity comparison ($O(1)$, $O(\log n)$, $O(n)$, $O(n \log n)$, $O(n^2)$).
- Gradient descent convergence steps and loss landscapes.
- Binary search halving steps vs linear search comparisons.
- Custom functions where visual curve intuition assists understanding.

## Pedagogical Invariants
1. **Never show all labels**: At least one curve, coordinate, or direction is replaced with a `[???]` blank.
2. **Predict-First Challenge**: Always pose an explicit prediction prompt (e.g., "Which curve represents $O(n \log n)$?").
3. **Self-Contained Export**: Output is rendered as inline SVG or HTML page.
