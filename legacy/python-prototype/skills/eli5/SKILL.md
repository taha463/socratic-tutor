# ELI5 Skill

## When to Use
- Complete beginners (Rung 3)
- Highly abstract concepts (recursion, concurrency, memory allocation, hashing)
- High learner frustration (> 0.7) where technical jargon creates cognitive friction

## Inputs
- `concept` (str): Name of concept
- `analogy` (str): The everyday metaphor
- `mapping_question` (str): Question asking learner to map the metaphor back to code/logic

## Outputs
- Self-contained styled HTML card with analogy block and mapping challenge
