# Three.js 3D Spatial Skill (Plugin)

## When to Use
Use when teaching spatial, geometric, or multi-dimensional linear algebra concepts:
- 3D matrix transformations (rotations, shears, scaling).
- 3D vector spaces and coordinate frame projections.
- Machine learning hyperplanes in 3D feature spaces.

## Output
Self-contained HTML file embedding Three.js + OrbitControls, rendering a responsive 3D interactive scene with interactive orbit/zoom controls and pedagogical blanks.
