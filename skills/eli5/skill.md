# ELI5 Skill

## When to Use
Use when a learner is on Rung 3 (Analogy) or struggling with the initial mental model of an abstract concept (recursion, pointers, caches, transactions).

## Invariant
Always pair the analogy with a mapping question requiring the student to connect the everyday object back to the domain.
