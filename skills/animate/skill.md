# Animate Skill (In-Browser Step Animation Player)

## When to Use
Use when a learner needs to see a process unfold over time without installing heavy external dependencies like Manim or ffmpeg.

## Invariant
Supports play, pause, next-step, and scrubber controls. Features at least one prediction step where elements are masked with blanks.
