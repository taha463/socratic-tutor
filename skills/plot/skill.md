# Plot Skill

## When to Use
Use when teaching algorithmic scaling (Big-O: O(1), O(log n), O(n), O(n log n), O(n^2)), loss curves, or mathematical functions.

## Invariant
At least one curve or coordinate is marked as `[???]` and requires student prediction.
